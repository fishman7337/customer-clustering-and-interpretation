# Changelog

All notable changes to this project will be documented here.

## 0.1.0 - 2026-04-29

### Added

- Production-style `src/customer_segmentation` package.
- CLI for training K-Means and exporting model, metrics, and labelled segments.
- Pytest coverage for data preparation, modeling, and CLI behavior.
- GitHub Actions CI for linting, tests, Bandit, and dependency audit.
- Dependabot configuration for GitHub Actions and Python dependencies.
- Data, model, MLOps, repository, security, contribution, and conduct documentation.
- Normalized folder structure for notebooks, docs, data, models, and reports.

### Changed

- Moved the original notebook into `notebooks/customer_segmentation_analysis.ipynb`.
- Moved the presentation into `docs/presentation/customer_segmentation_presentation.pptx`.
- Updated notebook paths to use `data/raw/` and `models/`.
