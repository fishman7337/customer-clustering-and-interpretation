# Documentation

This folder contains project documentation that supports reproducibility, review, and
responsible reuse.

## Key Documents

- `PROJECT_CONTEXT.md`: academic and institutional context.
- `DATA.md`: input schema, preprocessing, and data governance.
- `MODEL_CARD.md`: model use, limitations, metrics, and ethical notes.
- `MLOPS.md`: local and CI workflow for training and validation.
- `REPOSITORY_STRUCTURE.md`: folder responsibilities.
- `presentation/`: original CA2 presentation deck.
