# Code of Conduct

## Our Standard

This project should remain a respectful, inclusive, and learning-focused space. Contributors
are expected to communicate professionally, assume good intent, and give feedback in a way
that helps the work improve.

## Expected Behavior

- Use welcoming and respectful language.
- Accept constructive feedback gracefully.
- Keep discussions focused on the project and its educational goals.
- Credit ideas, data, and code that come from other people or sources.
- Be mindful that this repository may represent academic work.

## Unacceptable Behavior

- Harassment, discrimination, insults, or personal attacks.
- Sharing private information without permission.
- Plagiarism or misrepresenting authorship.
- Introducing malicious code, secrets, or intentionally misleading results.

## Enforcement

Maintainers may remove comments, issues, pull requests, or contributions that violate this
code of conduct. Serious or repeated violations may result in blocked participation.

## Reporting

Report concerns privately to the repository owner. Include enough context for the issue to
be reviewed fairly.
